AURORA HAIR & BEAUTY EQUIPMENT — PROFESSIONAL WEBSITE UPDATE

This package contains a redesigned, customer-friendly GitHub Pages website.

WHAT CHANGED
- More professional, modern luxury-style design.
- Clear South African Rand (R / ZAR) price shown on EVERY product card.
- Search box for products.
- Category filters.
- Price/name sorting.
- Product count.
- Larger, cleaner product cards.
- One-tap WhatsApp ordering for every product.
- Customer-friendly Combo Deals section.
- Mobile-friendly layout, including a floating WhatsApp button.
- Sticky navigation and clearer Contact section.
- Existing product images and products are retained.

HOW TO UPLOAD TO GITHUB
1. Open your GitHub repository.
2. Open the repository for Aurora_Hair_Beauty_Equipment_Website_FIXED_READY.
3. Replace the existing index.html with the index.html from this package.
4. Keep the existing images folder and upload/replace the images from this package if needed.
5. Commit the changes.
6. Wait a few minutes for GitHub Pages to rebuild.
